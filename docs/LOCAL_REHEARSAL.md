# 本地场景排演

打开故事或大纲中的一场情节，关联两位人物，在“本地人物排演”中选择他们的角色。填写本场事项，选择交付、透露、请求中的一种，或展开编辑全部动作与可观察后果。人物卡和当前场景提供人物、阶段名称与已写明的目标。把握、失败代价及行动前提是作者对这一场的假设。每人的信念单独计算，试演不会增加作品事实。

| 引擎 | 用途 | 安装 |
| --- | --- | --- |
| [PsychSim](https://github.com/usc-psychsim/psychsim/tree/56ef6e95a9f22dab3a4c216f34494363c78b621f)，MIT | 比较按自己的信念预期的收益，选择行动或暂缓 | 随后端 requirements 安装 |
| [Praxish](https://github.com/mkremins/praxish/tree/727d92511257ca1e5714b7027ba4e0c558568516)，MIT | 用社会情境的规则枚举行动，在分支中执行前一个动作，找出对方新增的回应机会 | 原版核心源码与许可证随仓库提供，后端主机需要 Node 20+ |
| [Sabre](https://github.com/sgware/sabre/tree/73a128123b10a57843068b69d0b0e0601f37488a)，GPL-3.0 | 根据作者所选终点及双方意愿搜索多步路径，也能返回没有解 | Java 21+，运行下方安装命令 |
| [FAtiMA Toolkit](https://github.com/GAIPS/FAtiMA-Toolkit/tree/56b7cbd992f953cfe21a7b12cb1a0e6cdf6ccf9f)，Apache-2.0 | 对观察到的事件计算情绪和心境，供回应者选择动作时参考 | .NET 8 SDK、Git，运行下方安装命令 |

Praxish 是 Versu 的部分重建。Sabre 和 FAtiMA 分别采用其他团队的意图规划和情绪评价实现。首次安装需联网，排演只启动本机程序。对于服务器上运行的网页，把对应运行环境安装在运行 FastAPI 的机器上。在仓库根目录运行以下命令，再刷新页面。

```sh
python -m pip install -r backend/requirements.txt
python backend/rehearsal_engines/install.py
```

可给安装脚本传 `sabre` 或 `fatima` 单独安装。默认使用当前用户目录下的 `.novix/engines`，部署时可用 `NOVIX_ENGINE_DIR` 指向服务账号可读的目录。桌面启动方式仍见项目 README。安装脚本固定上游提交，校验 Sabre JAR 的 SHA-256，本机从 FAtiMA 源码构建桥接程序。可分别启用就绪的引擎。

## 排演如何产生结果

首版覆盖两人之间“一次主动行动及一次回应”。给主动选项配置收益 3，根据人物对成功的把握和失败代价计算预期，审慎选项的代价为 0.4。可用前提负责约束行动。前一人暂缓或保密时，对方没有观察到本场设定的效果，因而不会凭空回应。目标文字供作者核对，自由文本世界设定需要作者转换为本场条件。

情绪评价的输入是回应者对已观察事件的利害判断（−10 至 10）。FAtiMA 输出情绪和心境，Novix 用“原失败代价减去心境的一半”调整回应者的风险估计，限制在 1 至 12 之间。这个系数是产品的模拟规则。Sabre 的目标路径单独展示，作者可对比它与人物自发选择的差异。

排演生成可编辑候选。采纳到手稿、预览并确认后，方案和参数随现有排演保存，相关章节仍可在预览里查看。本地候选的确认不会排队调用云端改写，也不会把预测写为已发生的剧情。
